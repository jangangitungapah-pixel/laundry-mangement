# Screen Map — Laundry Management SaaS MVP

Dokumen ini menurunkan arsitektur informasi pada PRD versi 0.1 menjadi daftar halaman untuk validasi user flow dan wireframe. `docs/PRD.md` tetap menjadi sumber keputusan produk.

## Konvensi

- `tenantSlug`, `orderId`, `customerId`, dan `tenantId` adalah parameter route, bukan bukti otorisasi. Akses tetap harus diverifikasi dari session, membership, permission berbasis kapabilitas, assignment outlet, dan entitlement.
- Nama role pada tabel adalah preset awal. Frasa **sesuai kapabilitas** berarti akses final tidak boleh hanya bergantung pada nama role.
- Pada route tenant, permission-denied tidak boleh mengungkap keberadaan atau data tenant lain. Tenant read-only masih dapat melihat data yang diizinkan, tetapi tindakan mutasi harus dinonaktifkan dengan penjelasan status subscription.
- Semua state memakai Bahasa Indonesia, format rupiah, serta tanggal dan waktu sesuai timezone tenant.
- Semua keputusan `TBD` dicatat di `docs/OPEN_DECISIONS.md`. Keputusan P0 wajib selesai sebelum wireframe; placeholder hanya boleh digunakan untuk P1/P2 sesuai prioritasnya.
- Route tambahan yang belum ditetapkan PRD ditulis `TBD` dan tidak boleh dianggap kontrak implementasi sebelum keputusan terkait disetujui.

## Cakupan Interaksi Tanpa Route Baru

Interaksi berikut tetap diperlukan, tetapi untuk menjaga scope MVP dapat ditempatkan sebagai dialog/drawer/state pada halaman yang sudah ada. Wireframe harus menentukan bentuknya tanpa otomatis menambah route:

- logout dan pemilih tenant pada app shell; logout mengakhiri session lalu kembali ke `/login`, sedangkan pemilih tenant hanya menampilkan membership aktif;
- tambah/edit outlet pada halaman **Outlet**;
- tambah/edit/nonaktifkan layanan dan override harga pada halaman **Layanan dan Harga**;
- undang/nonaktifkan pegawai serta assignment outlet pada halaman **Pegawai**;
- catat pembayaran, void, refund, pembatalan, dan koreksi teraudit dari permukaan yang disetujui melalui `P0-PAY-03`, sesuai permission;
- cash in, cash out, input kas fisik, dan konfirmasi tutup kas pada **Kas dan Tutup Kas**;
- extension trial, kompensasi, suspend, dan reactivate pada **Detail Tenant — Super Admin**;
- hasil checkout subscription kembali ke **Billing dan Subscription**; redirect browser tidak boleh mengaktifkan subscription tanpa verifikasi server/webhook.
